# ADR-0001 — Escopo do produto e piloto

Status: Accepted
Data: 13/10/2026

## Decisão
- Plataforma: Web.
- Público: ateliê/sob medida + modelista/confecção.
- Editor: Advanced.
- Piloto: `PILOT-001 — Flat Shirt Core`.

## Consequências
- Kernel paramétrico próprio.
- Editor deve suportar geometria paramétrica, override e livre.
- Código de produção permanece bloqueado até aprovação do gate de domínio/POC.
